# 滑雪场管理系统

> 滑雪场的服务门户：场地、教练、雪具统一按时段预约，钱包支付 + 现场核销，后台管资源看趋势，用户端还带一个能流式输出的 AI 滑雪助手。

## 一、系统介绍

一套前后端分离的滑雪场管理系统，三条业务线并行：普通用户的滑雪服务门户、教练工作区、管理员后台。

系统的核心是**时段**。教练、雪具、场地三类资源，管理员先按日期配置可约时段（起止时间、可约数、时段价格），用户选时段下预约单，下单时校验启用状态和剩余容量，成功后已预约数 +1;30 分钟没付款，定时任务自动取消订单并把容量还回去，不会出现"占着时段不付钱"的情况。支付走钱包余额，成功后生成唯一核销码，用户到现场出示，管理员扫码核销，订单转已完成，之后才能评价。评价会回写教练的预约数、完成数和平均分。

另外接了个 DeepSeek 滑雪助手，走 SSE 流式输出，首条提问自动建会话并用前 20 字当标题，每次带最近 10 条消息做上下文，回答留存在库里可以翻回去看。

### 系统亮点

**① AI 智能助手流式对话**
DeepSeek 接口 + SSE 增量推送，回答一个字一个字出来，不用等整段生成。会话自动创建、历史留存、只带最近 10 条上下文，连续追问不会跑题也不会把 token 撑爆。

**② 教练 / 雪具 / 场地一体化预约**
三类资源用同一张预约订单承载，靠预约类型区分。选时段、校验容量、算金额、占容量的逻辑一套跑通，新增资源类型不用重写订单流程。

**③ 时段容量与超时归还**
每个时段记录最大可约数、已预约数和时段价。下单前用「最大可约 − 已预约」算余量，超了就拒绝;定时任务每分钟扫一遍，超 30 分钟未支付的订单自动取消并归还容量。

**④ 钱包支付与退款审核**
充值、消费、退款、后台调整全部走交易流水，余额变动有据可查。退款由用户发起、管理员审核，同意后退回钱包并写退款流水，不直接删单。

**⑤ 订单核销与服务评价**
支付成功即生成唯一核销码，管理端输码或扫码核销，只有已支付/使用中的订单能核销。核销后订单转已完成，用户才能提交 1–5 分评分和文字评价，评价结果回写教练统计。

**⑥ ECharts 运营数据分析**
数据看板汇总注册用户、教练、场地、雪具、订单、营收、评价数，配近 7 天订单与营收双轴趋势、预约类型分布环图、预约状态分布、营收趋势;单独的预约数据分析页按类型、状态、时间做进一步拆解。

**⑦ 资源建档与资质审核**
教练档案带擅长项目、资质等级、从业年限、课时价、评分和审核状态;雪具按类型管品牌、规格、库存、图集;场地管难度、容纳人数、开放时间、开放状态。教练资质走待审核 / 已通过 / 已驳回。

## 二、角色与功能

| 角色 | 主要使用范围 |
| --- | --- |
| 普通用户 | 浏览场地/教练/雪具/公告，选时段下单，钱包充值支付、申请退款、查看核销码、提交评价，使用 AI 滑雪助手咨询 |
| 教练 | 维护个人简介、擅长项目、资质等级、从业年限、收费标准与可约时段，查看本人预约订单及统计、评价 |
| 管理员 | 维护用户、教练资质、场地、雪具类型与雪具、预约时段、公告、评价、交易流水，处理退款、订单核销，查看运营与预约分析 |
