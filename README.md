# <font style="color:#48b378;">一、项目介绍</font>
## 1.1 技术介绍
①：架构：B/S、MVC、前后端分离、用户前台+管理后台、管理员/普通用户/教练三角色

②：系统环境：Windows

③：开发环境：IDEA、JDK17、Maven、MySQL、Node.js

④：后端技术：Java、Spring Boot 3.3.1、Spring MVC、MyBatis-Plus、MySQL、JWT、Apache POI、DeepSeek API

⑤：前端技术：Vue 3、Vite、Element Plus、Vue Router、Pinia、Axios、ECharts、qrcode、jsQR

## 1.2 系统亮点
√ 三类预约统一管理：将订场地、找教练、租雪具纳入统一预约订单流程，串联时段选择、支付、核销、完成与评价，方便用户安排滑雪行程。

√ DeepSeek AI助手：接入DeepSeek，支持流式回复、历史会话及消息管理，为用户提供对话咨询入口；使用时需配置有效API密钥。

√ 热门推荐排序：场地按有效预约量排序，教练按预约总数及评分排序，雪具按有效租赁订单量排序，结合场地开放状态、教练审核状态及雪具库存筛选推荐资源。

√ 排班冲突校验：创建时间段时检查已有时段重叠情况，配合时段启用禁用与预约容量管理，方便维护可预约资源。

√ 二维码核销：支付后生成核销码，用户可展示核销二维码，后台支持二维码识别及订单核销，衔接线上预约与现场服务。

√ 钱包与退款闭环：支持账户充值、余额支付、退款申请及管理员审核，退款回到用户钱包并记录交易流水，方便查询资金变化。

√ ECharts运营分析：提供数据看板、预约分析及交易分析，结合Excel导出，帮助管理人员查看预约和交易情况。

√ 教练账号自动创建：管理员新增教练时自动生成关联登录账号，减少资料与账号分别录入的工作。

√ 教练服务数据统计：完成、评价等业务操作联动更新教练预约总数、完成数及综合评分，方便管理人员了解服务情况。

√ 预约容量与金额计算：下单时校验时段启用状态和剩余可约数量，按时段价格与预约数量计算金额并更新已约数，取消或同意退款时归还时段名额。

√ 支付时限提示：支付页展示30分钟倒计时，后端支付接口校验订单是否超时，帮助用户及时完成付款。

## 1.3 系统功能
### 1.3.1 管理员端
√ 用户管理：账号新增、编辑、删除、批量删除、条件查询、密码重置。

√ 教练管理：维护教练资料及教学价格，新增教练时自动创建关联登录账号，查看综合评分、预约总数及完成数。

√ 场地管理：维护难度等级、容纳人数、开放时间、价格、封面、图片集、简介及开放/维护/关闭状态。

√ 雪具管理：维护雪具资料、品牌、租赁价格、库存数量及图片，管理雪具分类。

√ 预约配置：场地排班、教练排班、雪具预约配置，按星期维护起止时间、时段价格和最大可约数，支持时间段新增、编辑、删除、启用禁用及重叠冲突校验。

√ 预约订单管理：按用户、类型、状态等条件查询，查看订单信息，取消待支付订单、完成已支付/使用中订单、删除及批量删除订单。

√ 退款审核：同意或拒绝退款申请，同意后退回用户钱包并记录退款流水。

√ 订单核销：支持手动输入核销码、上传二维码图片识别并核销。

√ 评价管理：查询用户评分及评价内容，删除及批量删除评价。

√ 交易流水：查询充值、消费、退款记录，查看金额、余额及关联订单。

√ 公告管理：新增、编辑、删除及批量删除公告，维护富文本内容、发布时间和发布状态。

√ 数据看板：用户、教练、场地、雪具、订单、营收、评价概览，订单与营收趋势及预约类型分布。

√ 预约分析：预约总数、金额、完成率、取消数、今日预约、预约趋势及类型占比。

√ 交易分析：交易总数与金额、充值额、消费额、退款额、今日交易、交易趋势及类型占比。

√ Excel导出：支持用户、教练、场地、雪具、预约订单、交易流水数据导出。

### 1.3.2普通用户端
√ 注册登录、图形验证码、找回密码、个人资料维护、头像上传、修改密码。

√ 首页热门场地、热门教练及热门雪具推荐，浏览资源列表与详情。

√ 场地按名称和状态筛选；教练按等级、姓名、擅长项目筛选；雪具按分类、名称和品牌筛选。

√ 查看资源介绍、价格及可预约时段，切换周历、选择时段和预约数量，确认订单并提交预约。

√ 余额支付、30分钟支付倒计时、余额不足时跳转充值、取消待支付订单。

√ 我的预约：按预约类型及状态筛选，查看订单详情、支付信息、预约时段及核销码/二维码。

√ 售后与评价：申请退款、查看退款处理状态，订单完成后提交评分及评价。

√ 我的钱包：查看账户余额、选择预设或自定义金额充值，按充值/消费/退款类型查询个人流水。

√ 公告列表及详情查看。

√ AI智能助手：发起新对话、流式接收回复、切换历史会话、查看历史消息、删除会话。

### 1.3.3教练端
√ 教练资料维护：编辑姓名、个人简介、擅长项目、资质等级、从业年限、联系电话及头像。

√ 服务价格设置：修改每小时教学价格。

√ 我的预约查询：查看预约自己的订单、预约用户、预约日期与时段、金额及支付状态，支持按预约状态筛选和分页。

√ 我的评价查看：查看用户对自己的评分、评价内容及评价时间。

√ 账号管理：维护个人账号信息、修改密码、退出登录。
